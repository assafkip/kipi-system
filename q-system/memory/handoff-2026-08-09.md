## Two things that will bite whoever picks this up

**Do not launch the PR reviewer in the same shell call as a push.** It reads the
head twice and refuses when it moves, so it races your own push and posts nothing.

**Always `git -C <path>`.** A failed `cd` silently falls back to the session
default cwd, so the next git command runs in another session's checkout. This
bit the session again today.
